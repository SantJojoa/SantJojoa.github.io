Soluciones reales que he construido, desde plataformas institucionales hasta aplicaciones personales.

SIVAT Nariño

Plataforma para llevar registro de programaciones de todas las subdirecciones del Instituto Departamental de Nariño. Incluye validación de cruces en programaciones, aprobación/rechazo según rol, adherencia a programaciones y control por roles.

PHP MySQL JavaScript

SINSI Nariño

Plataforma para el control de la salud infantil de cada municipio del departamento de Nariño. Permite el seguimiento centralizado de indicadores de salud infantil a nivel departamental.

PHP MySQL JavaScript

FEVRIPS

Plataforma para validar RIPS de IPS integrando la API privada del Ministerio de Salud de Nariño. Incluye validación de facturas en JSON y comparación de datos del ministerio con datos locales.

PHP MySQL Node.js REST API

Juventud Conecta

Plataforma web para potenciar la visibilidad y participación de jóvenes en eventos sociales de alto impacto en Pasto, Colombia. Permite acceder a información de eventos, registrarse y conectar con iniciativas comunitarias.

React TypeScript Tailwind
